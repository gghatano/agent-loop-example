# Walkthrough

Issue #1「モックと実装の3画面を一致させる」を、AI に丸投げしたときの記録。
起きたことだけを書く。予想は書いた時点のものを残し、外れたら外れたと書く。

## 0. 人間がやったこと

モック（`mock/`）、データ（`fixtures/`）、ルートだけの FastAPI の骨組み、そして評価関数を置いた。
評価関数は `scripts/vrt.py` だ。モックと実装を同じ Chromium で撮って、ピクセル差分と console error を数える。
初期状態の差分は、3画面とも約11%あった。

AGENTS.md の Project rules には、2行しか書いていない。モックが正であることと、値を直書きしないことだ。

走らせる前に、予想を2つ立てた。

- `gh` の認証がないので、Issue を読むところで Permission の壁に当たるだろう。
- 「直書きしない」は文章のルールでしかなく、check はそれを検査していない。モックの HTML をそのまま写せば VRT は 0 になる。AI はその穴を通るかもしれない。

## 1. Run 1：3周とも同じ場所で止まった

Permission の壁には当たった。ただし原因は `gh` の認証ではなく、その手前にあった。
ヘッドレスの `claude -p` は、未信頼のワークスペースでは `.claude/settings.json` の allow を丸ごと無視する。用意した許可は、一つも効いていなかった。

AI の振る舞いは正しかった。Issue を読めないので推測で進めず、3周とも「止まる」と返してきた。
壊れていたのはループのほうだ。`loop.sh` は check の色しか見ていない。AI が人間を呼んでいても気づかず、同じ壁に向けて3回起動し直した。

`/postmortem` を AI に走らせると、分類は Permission で、診断もほぼ合っていた。見落としは一つで、許可を直しても `gh` の認証で落ちることだった。
人間の判断で、次の4つを `loop.sh` に入れた（afb39b5）。

- 許可は `--allowedTools` で明示する
- Issue の本文は人間側で取ってきて、`tasks/issue-N.md` で渡す
- `/goal` の引数とループへの指示を分ける
- `.agent/BLOCKED` か、1周まるごと何も変わらなかったら止める

## 2. Run 2：1周目で緑。ただしコミットできなかった

実装は1周目で終わった。3画面とも `diff=0px`、console error は 0。
favicon の 404 も、AI が自分で見つけて潰していた。モックは `file://` で開くので favicon を取りに行かないが、実装は取りに行く。人間が仕込んだつもりのない差だった。

2つめの予想は外れた。テンプレートは全部 `fixtures` から描画していて、直書きは一つもない。CSS も、`mock/style.css` を複製せずにそのまま配信していた。
とはいえ、評価関数の穴が塞がったわけではない。今回は通られなかった、というだけだ。

止まったのは、最後の `git add` だった。許可リストに入れたはずのコマンドが、承認待ちになった。
再現してみると、許可は前方一致で効いていて、`git -C . add` のような書き方だけが拒否される。AI が実際にどう書いたかは、ログに残っていない。

AI は `.agent/BLOCKED` に状況と選択肢を書いて止まった。Run 1 で入れた出口が、そのまま機能した。
人間が選択肢1を選び、作業ツリーに手を加えずにコミットして PR #2 を出した。
`loop.sh` の許可は、コマンド単位から道具単位（`git:*`, `uv:*`）に広げた。取り返しのつかない操作だけを `--disallowedTools` で塞いでいる。

## 3. 途中でわかったこと

未信頼のワークスペースでも、Stop hook は動く。
check が赤い状態で「done とだけ返して」と頼んだら、AI は VRT を直しにかかった。hook が差し戻したということだ。
許可リストは無視されるのに、hook は効く。ループを仕組みで閉じるという設計は、ヘッドレスでも成り立っていた。

Context は 0 件で、AGENTS.md には1行も足していない。
2行の Project rules と、モックという「見ればわかる正」で足りた。プロンプトを直す出番は、一度もなかった。

## 5. まだ決めていないこと

値の直書きを、評価関数で検出するかどうか。
`fixtures` を差し替えて描画し、画面が変わることを確かめるテストを書けば、検出はできる。そのテストを書くのは AI か、人間か。
今回は通られなかったので、まだ書いていない。最初に通られたときが、その判断をするときになる。
