## 2026-10-10 同名メンバーの扱い
- 決めたこと: メンバーの一覧に同じ名前が複数あっても、別人として数える。役割は名前が担当者と完全一致すれば「担当」にする（部分一致はしない）
- 理由: データには人の ID がなく、名前しか区別の手がかりがない。重複を畳むと人数が実際より少なく出る
- 捨てた案と、捨てた理由: 重複を1人に畳む案（同名の別人を消してしまう）、先に出た1人だけを担当にする案（データの並び順に意味を持たせることになる）
- 見直す条件: メンバーに ID が付いたとき
